# ApuntesTypeScript

Bienvenidos al repositorio **ApuntesTypeScript**, un espacio dedicado a almacenar los apuntes, ejemplos y código realizado durante las clases de la asignatura **Arquitectura y Programación de Sistemas en Internet**, utilizando **TypeScript** como lenguaje principal.

## 📚 Descripción

Este repositorio contiene una recopilación de apuntes, ejemplos, ejercicios y código desarrollado durante las clases.

El contenido se irá actualizando a medida que avance la asignatura, con el objetivo de mantener organizado todo el material visto en clase y facilitar su consulta y repaso.

## 📂 Organización

El repositorio estará organizado por clases y/o temas, incluyendo:

* Código realizado durante las clases.
* Ejercicios y ejemplos prácticos.
* Apuntes sobre TypeScript.
* Conceptos relacionados con la arquitectura y programación de sistemas en Internet.
* Prácticas y material adicional de la asignatura.

## ⚠️ Errores o Mejoras

Si encuentras algún error o tienes alguna sugerencia para mejorar el contenido, no dudes en comunicarlo abriendo un **issue** o enviando un **pull request**.


## 🚀 Contribuciones

Las contribuciones son siempre bienvenidas. Si tienes algo que agregar, corregir o mejorar, puedes hacerlo mediante un **pull request**.
